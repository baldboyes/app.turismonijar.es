## SDD & OpenSpec Protocol
- This project uses Gentle AI in `openspec` mode.
- Any technical design, task breakdown, or exploration report MUST be written as a Markdown file (`.md`) inside the `./openspec/` directory (under `specs/`, `designs/`, or `tasks/`).
- NEVER store project-specific technical documentation or architecture designs exclusively in your global session logs (`~/.gemini/`). Everything must be committable to Git.
